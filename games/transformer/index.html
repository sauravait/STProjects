What is an Electrical Transformer?

A transformer is a static electrical device that transfers electrical energy between two circuits using electromagnetic induction. It can raise (step up) or lower (step down) AC voltage levels while keeping power approximately constant.

Key Facts

  • 🔌 Works on AC (Alternating Current) only — not DC
  • 🧲 Uses Faraday's Law of electromagnetic induction
  • ⚡ No direct electrical connection between input and output
  • 🏭 Essential for efficient long-distance power transmission
🌍

Every power outlet in your home works because transformers step down the high-voltage grid (typically 11 000 V – 400 000 V) to safe household voltages (110 V – 240 V).

Scene 3 of 7

How a Transformer Works

  1. 1
    AC enters primary winding — alternating current flows through the primary coil (blue), creating an alternating magnetic field.
  2. 2
    Alternating magnetic flux in core — the iron core channels the rapidly changing magnetic flux (green arrows) through its cross-section.
  3. 3
    Flux links to secondary winding — the same changing flux passes through the secondary coil (red), inducing an EMF (Faraday's Law).
  4. 4
    AC output delivered — the induced EMF drives alternating current through the connected load. No direct electrical path exists between input and output.
Energy transfers magnetically — there is no direct electrical connection between the two circuits.

Step-Up Transformer

When the secondary winding has more turns than the primary (Ns > Np), the output voltage is higher than the input — and the output current is proportionally lower.

Vs / Vp = Ns / Np > 1

Output voltage > Input voltage  |  Output current < Input current

Real-world example: Power stations step up 11 kV to 400 kV for efficient long-distance transmission through overhead lines.

Step-Down Transformer

When the secondary winding has fewer turns than the primary (Ns < Np), the output voltage is lower than the input — and the output current is proportionally higher.

Vs / Vp = Ns / Np < 1

Output voltage < Input voltage  |  Output current > Input current

Real-world example: Your mobile charger contains a step-down transformer that converts 240 V mains supply to 5 V for charging.

1×
Vs (output)
0.33×
Fewer secondary turns → lower voltage, higher current. Used in chargers and appliances.

Formulas & Key Concepts

Vs / Vp = Ns / Np = Ip / Is

Turns ratio governs both voltage and current transformation.

Vp · Ip ≈ Vs · Is

Ideal transformer: input power equals output power (100% efficiency).

📌 Key Takeaways

  • Transformers work on AC only via Faraday's Law.
  • Turns ratio = Ns / Np determines voltage transformation.
  • Step-up: Ns > Np → higher voltage, lower current.
  • Step-down: Ns < Np → lower voltage, higher current.
  • Ideal transformer conserves power: Vp·Ip = Vs·Is.
